# RobotX 2026 USV (Crusader)

Jetson Orin Nano + Pixhawk (ArduRover). ROS 2 Humble in Docker container `crusader`.
Code lives on the HOST at ~/robotx_ws, bind-mounted into the container at /root/robotx_ws.

## Hardware map
- Pixhawk: /dev/serial/by-id/usb-ArduPilot_Pixhawk1_3A001F...-if00 (owned by MAVProxy ONLY)
- LED Arduino (CH340, no serial number — do not add a second CH340): usb-1a86_USB_Serial-if00-port0
- OAK-D LR camera: MX ID 194430101110C82F00 (idle state shows as "Luxonis Bootloader" in lsusb — normal)
- RC: RC7 = arm/e-stop (RCx_OPTION=165; 994 estop / 1498 mid / 1995 arm). Channel 8 = mode (SC switch).

## Start order (all inside container: docker exec -it crusader bash)
1. ./scripts/start_mavproxy.sh <laptop-ip>
2. ros2 launch robotx_2026 core.launch.py
LED: red = disarmed/e-stop, yellow = armed manual, green = auto.

```
~/robotx_ws/                          <- workspace root (on the Jetson host; appears
│                                        as /root/robotx_ws inside the container)
├── build/                            <- generated by colcon build - never edit
├── install/                          <- generated by colcon build - never edit
├── log/                              <- build logs - never edit
└── src/
    └── robotx_2026/                  <- THE REPO (git lives here)
        ├── package.xml               <- ROS 2 package manifest (name, dependencies)
        ├── setup.py                  <- defines the nodes: led_node, pixhawk_led_node
        ├── setup.cfg                 <- ROS 2 install paths (boilerplate)
        ├── .gitignore                <- keeps build junk out of git
        ├── README.md                 <- hardware map, RC config, start order
        ├── resource/
        │   └── robotx_2026           <- empty marker file ROS 2 requires
        ├── launch/
        │   └── core.launch.py        <- starts led_node + pixhawk_led_node together
        ├── firmware/
        │   └── LED.ino               <- Arduino sketch flashed on the LED controller
        │                                (record copy - edit + reflash via Arduino IDE)
        ├── scripts/
        │   └── start_mavproxy.sh     <- starts MAVProxy, the ONLY owner of the
        │                                Pixhawk USB port; usage: ./start_mavproxy.sh <LAPTOP_IP>
        ├── tools/
        │   └── oak_view.py           <- camera check: streams video to http://<jetson-ip>:8080
        └── robotx_2026/              <- the Python package (all ROS nodes live under here)
            ├── __init__.py
            └── api/
                ├── __init__.py
                ├── led/
                │   ├── __init__.py
                │   └── led_node.py                   <- listens on /led_state, drives the
                │                                        Arduino over serial, auto-reconnects
                └── pixhawk/
                    ├── __init__.py
                    └── pixhawk_led_status_node.py    <- reads Pixhawk state via MAVLink UDP,
                                                         publishes /led_state (1=red 2=yellow 3=green)
```
